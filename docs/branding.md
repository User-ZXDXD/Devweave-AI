# 产品更名与兼容性说明

当前产品名称统一为 **DevWeave AI**，仓库为`User-ZXDXD/Devweave-AI`，示例应用配置为`APP_NAME=DevWeave AI`。

本轮覆盖隐藏配置、界面、通知、模型提示词、启动脚本、知识库、评测展示与测试文字。示例仓库显示名更新为`course-demo/devweave-sample-api`；已有合成演示仓库保留UUID和关联Issue/PR/CI，只迁移名称，不重复创建或删除用户数据。

## 为什么少数技术标识保留旧值

| 保留项 | 原因 |
| --- | --- |
| PostgreSQL的现有数据库名、用户与示例连接默认值 | 展示更名不能导致连接到另一个空数据库；真实凭据由本地环境提供 |
| Docker数据卷、Milvus集合、SQLite演示文件与缓存命名空间 | 它们定位已有数据，产品更名不执行数据迁移 |
| MCP工具ID、历史事件名和路由前缀 | 维持已有工具客户端与已保存记录的兼容性；服务端/客户端展示标签已更新 |
| 向量/知识图谱UUID前缀、跨进程锁键 | 改动会导致记录重复或让旧新进程使用不同的锁 |
| 索引配置路径、工作树标记及内部工作分支名 | 继续识别用户已有配置与受管理的代码快照 |
| 历史评测套件ID、专属评测仓库ID与测试启用变量 | 保持历史结果可追溯，继续要求显式启用付费模型/独立数据库测试 |
| 忽略规则与演示仓库的旧名查找 | 防止旧运行文件意外上传，并使示例名称迁移可重复执行 |

这些不是遗漏的展示名称。逐文件允许的字符串与理由见`scripts/branding_compatibility.json`；任何未登记的旧名称会令自动检查失败，不能把整个文件随意排除。

```powershell
python scripts/check_branding.py
```

该检查读取Git管理的全部文件及未忽略的新文件，包含`.env.example`等点开头文件；二进制图片和Git历史不执行文本替换。旧提交、用户原始资料和真实`.env`不改写。更名不更新历史实验结果或声称新增模型实验。

知识库和评测问题中的展示名称更新会改变文件校验和。已有导入资料仍按原版本保存；需要评测新版本时，请使用干净的专属评测仓库或显式更新旧知识，不把不同资料快照的结果当成同条件对比。
